## Overview

Sonnox Oxford Drum Gate is a precision gate designed specifically for drums, with external trigger input, look-ahead detection, and precise attack and release timing for clean drum gating.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonnox Oxford Drum Gate** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Trigger Input** | External MIDI or audio trigger for drum machine-like gate timing |
| **Look-Ahead** | Lookahead detection opens gate perfectly ahead of drum transient |
| **Attack/Release** | Sub-millisecond attack and adjustable decay for tight gate timing |
| **Ducking Mode** | Invert for ducking effects triggered by drum hits |
